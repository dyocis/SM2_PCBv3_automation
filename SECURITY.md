# Security and safety reports

This project controls physical hardware. Treat unexpected fan, UV, Peltier, servo, temperature, or calibration behavior as a safety issue: stop the printer, disconnect power when appropriate, and do not continue testing unattended.

Do not publish private MCU identifiers, CAN UUIDs, network credentials, API keys, or unredacted logs in a public issue. For a non-sensitive defect, open a GitHub issue with sanitized logs and exact reproduction steps. If public disclosure would create an immediate safety or security risk, use GitHub's private vulnerability-reporting feature when it is enabled for the repository.

Reports and fixes are handled on a best-effort basis. There is no guaranteed response time, update schedule, or support commitment.
